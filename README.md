"# Proyecto2Btcmp" 
Autor: Ivan Gomez
Fecha: Octubre 2025
Tecnologías: Node.js, Express.js, MongoDB, Mongoose, Dotenv, CORS

Descripcion General:
Este proyecto corresponde a la base tecnica del backend de una aplicacion web full stack.
Tiene como objetivo establecer la conexion con una base de datos MongoDB y definir un modelo de usuario con operaciones CRUD basicsa (crear, leer, actualizar y eliminar).

Objetivos del proyecto
Configurar el servidor backend con Express.js
Conectar la applicacion a MongoDB con mongoose
Definir modelos  de datos (Usuario)
Probar endpoint usando Postman
seguir buenas practicas de estructura y control de versiones
